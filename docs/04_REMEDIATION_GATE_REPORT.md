## 4. Statistical values before / after (Gate 2)

and then multiplied by 2. Every stored `p_perm` was therefore inflated. The corrected function
returns `s / 2**n`. BH was also recomputed with a monotone step-up.

## 5. Atlas validation results (Gate 3)

### 5.1 Root cause (investigated, not forced)

1. `anndata.concat(ads, label="section")` was called **without `keys=`** → `obs["section"]`
   (and the copied `obs["sample"]`) were integer batch indices `0..13`.
2. The atlas concatenated the **scaled** `.X` (max 10.0) and then set `raw = ad` (scaled), so the
   rule-based `cluster_zscore_table`/`annotate_domains` ran on scaled values. Tumour clusters
   therefore collapsed to `Mixed`/immune/stroma. The annotation also used the per-sample `leiden`
   column rather than the atlas `leiden_atlas` clusters.

### 5.2 Before / after

| Property | Before (broken) | After (fixed) |
|---|---|---|
| `obs["sample"]` values | `0 … 13` (integers) | 14 specimen names |
| compartments | Immune 13,924 · Stroma 13,038 · Mixed 12,466 · **Tumour 0** | Mixed 20,287 · Immune 7,889 · Stroma 5,893 · **Tumour 5,359** |
| domains | fibroblast, B_cells, mixed, myeloid | + epithelial_tumour 3,598, proliferation 1,761, endothelial 2,129 |
| `03_domain_composition_fractions.csv` | 169 rows, index by Leiden id, almost all NaN | 14 clean rows, fractions sum to 1 |
| `validate_atlas()` | (no validator) | **[] — no problems** |
| determinism | — | two independent rebuilds → identical compartment counts |

The corrected atlas carries both label sets: `domain_sample`/`compartment_sample` (per-sample) and
`domain_atlas`/`compartment_atlas` (atlas-level).

**Note on composition numbers:** the atlas-level pre/post composition (pre Tumour 0.094 → post
0.140) differs slightly from the module-07 per-sample composition (0.091 → 0.161) because the
atlas uses Harmony-integrated atlas clusters while module 07 uses per-sample clusters. The report's
claim C16 cites module 07 (`07_paired_metrics.csv`) and is unchanged; the atlas table is a derived,
separately-validated artefact.
